Get started

Install Iris
Download and run the installer above. On first launch it sets up the MCP server and installs the Iris skill for your agent automatically.
Launch Iris and keep it open
The agent connects to the running Iris window. Sign into the sites you want it to use, and your sessions persist.
Add the MCP server to your agent
In Claude Code, run:
claude mcp add iris -- node %LOCALAPPDATA%\Iris\iris-mcp.mjs
Restart your agent
Restart Claude Code so it loads the Iris skill and the new tools.
Tell it what to do
“Research the top ticketing platforms and save me a CSV.” “Post this to X.” Anything you can do in a browser you're signed into.

What you can do

Deep research & competitor analysis · social ops (X, LinkedIn, Reddit…) · SaaS back-office · internal admin panels · job applications · bookings. Anything behind a login that no API gives you.
