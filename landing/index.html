Get started

  1. Install Iris
    Download and run the installer. On first launch it sets up the MCP server and installs the Iris skill for your agent.
  2. Launch it and keep it open
    The agent connects to the running window. Sign into the sites you want it to use; your sessions persist.
  3. Point your agent at it
    In Claude Code, run:
    claude mcp add iris -- node %LOCALAPPDATA%\Iris\iris-mcp.mjs
  4. Restart your agent
    Restart Claude Code so it loads the skill and the new tools.
  5. Tell it what to do
    Anything you can do in a browser you are signed into.

What it's for

Deep research and competitor analysis. Social operations across X, LinkedIn, and Reddit. SaaS back-office work in HubSpot, Notion, or Stripe. Internal admin panels, job applications, bookings. Anything behind a login that no API will give you.
